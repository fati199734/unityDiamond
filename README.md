# 💎 Unity Diamond Game

Un jeu 3D développé avec Unity où le joueur contrôle un personnage pour collecter des diamants dans un environnement interactif.

---

## 🎮 Fonctionnalités

- ✅ Contrôle d’un personnage 3D (Third-Person Controller)
- 💠 Collecte de diamants avec détection via `OnTriggerEnter`
- 🧠 Gestion d’inventaire (`PlayerInventory.cs`)
- 🔊 Logique d'événements (`UnityEvent`)
- 📦 Projet structuré avec Git & GitHub

---

## 🧰 Technologies utilisées

- Unity 2022.3 LTS (URP)
- C# (scripts Unity)
- Git + GitHub (versioning & collaboration)
